VPos Transaction API

POST /api/finance/add_vpos_transaction/

Sanal POS üzerinden gerçekleşen ödeme işlemlerini sisteme kaydetmek için kullanılır. Oturum gerektirmez.

Genel Bilgiler

URL
/api/finance/add_vpos_transaction/
Method
POST
Content-Type
application/json
Auth
Oturum gerekmez — CompanyId ve ValidationKey ile doğrulanır

Python

import requests

url = "https://arinet.arileasing.com.tr/api/finance/add_vpos_transaction/"

payload = {
    # Zorunlu
    "CompanyId":           "00000000-0000-0000-0000-000000000000",
    "ValidationKey":       "your-validation-key",
    "ProcessDate":         "2024-01-15T10:30:00",
    "MusteriTipi":         1,
    "PaidAmount":          1500.00,
    "LeasePostingGroupId": True,
    # Opsiyonel
    "FirmaAdi":     "Örnek Firma A.Ş.",
    "CurrencyCode": "TRY",
}

response = requests.post(url, json=payload)
print(response.status_code, response.json())
